# RSS-агрегатор — Vision & Scope

## Цель

Персональный агрегатор новостей и статей из RSS-источников с веб-интерфейсом,
который помогает быстро находить самое релевантное среди множества фидов.
Стартует как личный инструмент; архитектура сразу закладывается так, чтобы
позже открыть сервис для других пользователей без переписывания с нуля.

## Для кого

- **v1 (сейчас):** один пользователь, без авторизации, self-hosted запуск
  локально.
- **v2 (не сейчас, но закладывается в архитектуре):** несколько пользователей,
  каждый со своими источниками, категориями и фильтрами.

## Ключевые сценарии (Job Stories)

1. Когда у меня есть список интересных источников (блоги, новостные RSS),
   я хочу группировать их по категориям, чтобы не тонуть в едином потоке.
2. Когда я открываю приложение, я хочу видеть свежие материалы, отфильтрованные
   по релевантности (ключевые слова, теги, история чтения), а не просто в
   хронологическом порядке.
3. Когда материал неинтересен, я хочу быстро скрыть его или пометить, чтобы
   со временем фильтрация подстраивалась под мои интересы.

## Что сознательно НЕ входит в первую версию

- Многопользовательская авторизация и биллинг.
- Мобильные приложения.
- Push-уведомления и email-дайджесты (можно вернуться после MVP).

## Технологический стек и ограничения

- **Backend:** Python, FastAPI (переход с текущего CLI-скрипта).
- **Хранилище:** SQLite для старта — простота разворачивания; архитектура
  не должна жёстко привязываться к SQLite, чтобы позже перейти на PostgreSQL.
- **Frontend:** минимальный веб-интерфейс; можно начать с server-rendered
  HTML и не тащить сразу тяжёлый SPA-стек.
- Существующая логика (`fetch_rss`, `filters.py`, `sorter.py`, `exporter.py`)
  переиспользуется как доменная логика, но выносится из CLI-скрипта в
  независимый от интерфейса слой.

## Определение готовности MVP

- Источник можно добавить через UI (не через `sources.txt`).
- Источники группируются по категориям.
- Лента показывает новости с фильтрацией по ключевым словам/тегам.
- Сервис запускается как обычное веб-приложение (`uvicorn main:app`).

## Дорожная карта

1. Vision & scope — этот документ. ✅
2. Архитектурные драйверы и сценарии качества (ADD-итерация, ПР2).
3. Скелет FastAPI-сервиса с одним рабочим эндпоинтом — первый вертикальный срез.
4. Хранилище источников/категорий (SQLite) + CRUD.
5. Перенос текущей логики fetch/filter/sort в доменный слой, независимый от CLI и API.
6. Простой UI поверх API.
7. Умная фильтрация/рекомендации — ключевая фича продукта.
8. Архитектурная документация (шаблоны, MDA, DDD) — по мере роста функциональности,
   опираясь на то, что реально построено, а не наоборот.
